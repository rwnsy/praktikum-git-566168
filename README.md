# Praktikum Git — [NIM]

Website sederhana yang dibuat sebagai tugas praktikum Git & GitHub.

## Cara Menjalankan

1. Clone repo ini: `git clone https://github.com/username/praktikum-git-NIM`
2. Buka folder: `cd praktikum-git-NIM`
3. Buka `index.html` di browser

## Perintah Git yang Digunakan

| Perintah               | Penjelasan                        |
| ---------------------- | --------------------------------- |
| `git init`             | Inisialisasi repository baru      |
| `git add .`            | Staging semua perubahan           |
| `git commit -m "..."`  | Menyimpan snapshot perubahan      |
| `git branch`           | Membuat/melihat daftar branch     |
| `git switch -c nama`   | Membuat dan pindah ke branch baru |
| `git push origin nama` | Mengirim branch ke GitHub         |
| `git merge`            | Menggabungkan branch              |
| `git pull`             | Mengambil perubahan dari remote   |
| `git log --oneline`    | Melihat history commit ringkas    |
| `git rebase -i`        | Mengedit/menggabungkan commit     |
